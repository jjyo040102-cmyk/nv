## 합성 평가의 의미

정상 산출물 **8/8 허용**, 오류 산출물 **12/12 차단**, 워크플로 수명 주기 **4/4 통과**다. 단순 문자열 포함 여부만 검사한 대조 조건은 같은 오류 산출물 12개를 모두 허용했다. 이 대조는 경쟁 제품이나 모델 성능 비교가 아니다.

24개는 실제 사용자 업무 24건이 아니라 산출물 20개와 엔진 사례 4개이며, 각 1회 실행했다. 독립된 판정 로직을 사용하지만 XLSX 파싱에는 공통 ExcelJS 라이브러리가 쓰인다. 모델 호출과 외부 발송은 **0회**다. 자세한 [평가 설계](2026-10-23-evidence-benchmark.md)와 [측정 결과](2026-10-23-evidence-results.md)를 함께 읽어야 한다.

## 실제 제출 전 남은 항목

현재 로컬 환경을 값을 출력하지 않는 방식으로 읽기 확인했다. 저장된 공급자 키 **0개**, 활성 Gmail 연결 **0개**, 환경의 Nebius CLI 키와 Google OAuth 설정도 없다. 이 때문에 이번 실행으로 실 NVIDIA 모델 품질·크레딧·Gmail OAuth·실메일 결과를 입증하지 않는다.

1. **실 Nebius/NVIDIA:** 설정 화면에서 키·사용 가능한 NVIDIA 모델을 연결하고, 합성 문서로 실제 계획·오류 재계획과 영수증을 확보한다.
2. **실 Gmail:** OAuth 설정과 통제하는 테스트 계정으로 승인·발송·SENT 확인·새 답장 Wake를 검증한다.
3. **심사 접근:** 공개 소스 URL과 상시 HTTPS 실행 주소, 심사 계정을 준비한다. Docker 이미지는 이 환경에서 새로 빌드하지 않았다.
4. **제출 증거:** 영어 3분 미만 영상, 실제 사용자 영향력 측정, Nebius/NVIDIA 사용 피드백과 개발 이력을 마무리한다.

[공식 규정](https://nebiusglobalaihackathon.devpost.com/rules)의 제출 마감은 **2026-10-31 02:00 KST**, 심사 접근 유지 기한은 **2026-12-16 05:00 KST**다. 추천 트랙은 제품 범위를 고려한 **Best Apps and Agents**다.
